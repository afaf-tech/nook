## Not implemented yet

### Connection

- MongoDB connection (`conn.mongodb`) — catalogued, no driver yet
- Redis connection (`conn.redis`) — catalogued, no driver yet
- SQL Server connection (`conn.sqlserver`) — catalogued, no driver yet
- Oracle connection (`conn.oracle`) — catalogued, no driver yet
- HTTP tunnel (`conn.httpTunnel`) — not implemented; use SSH
- Cloud database connections (`conn.cloud`) — not implemented; connect over a tunnel instead

### Data

- Text and hex editors for blobs (`grid.blobEditor`) — bytes are shown and exported, not edited
- Edit the SQL of a row (`grid.rawMode`) — grid edits become SQL in the pending list instead

### Design

- Trigger and procedure editors (`schema.triggerEditor`) — not implemented
- Function editor with debugger (`schema.functionEditor`) — not implemented
- Sequence and type editors (`schema.sequenceEditor`) — not implemented
- Rebuild a table in place (`schema.tableRebuild`) — SQLite DDL that needs it says so instead

### Query

- Parameterised queries (`sql.parameterised`) — not implemented; literals are escaped on the client
- Stored procedure debugger (`sql.debugger`) — not implemented
- Query profiler (`sql.profiler`) — not implemented; EXPLAIN covers the common case
- Visual explain plan (`sql.planVisualiser`) — explain output is tabular, not drawn

### Import/Export

- Import XML (`tools.importXml`) — not implemented
- Import DBF (`tools.importDbf`) — not implemented
- Mapping wizard with preview (`tools.importWizard`) — columns map by name via columnMapping (src=target), preview is the first rows

### Transfer

- Column mapping (`transfer.columnMapping`) — name mapping via columnMapping (src=target) for transfer.data and imports
- Transfer speed settings (`transfer.speedTest`) — pages of 2000 rows per transaction

### Sync

- Delete rows missing from the source (`sync.dataDelete`) — part of the data sync diff
- Bi-directional sync (`sync.bidirectional`) — not implemented; choose a source
- Conflict rules (`sync.conflictRules`) — source wins, per column

### Backup

- Local backup copy (`backup.local`) — not implemented; the file is written where you say
- Compressed backups (`backup.compression`) — not implemented; the tools write plain files
- Encrypted backups (`backup.encryption`) — not implemented

### Automation

- Deploy jobs to an automation agent (`job.agent`) — not implemented; jobs run on this machine
- Chained jobs (`job.chain`) — "then" runs jobs in order after a success; cycles rejected at create time
- Job export and import (`job.profiles`) — the whole store is JSON under the app's config directory

### Monitor

- Live charts (`monitor.charts`) — the dashboard data feeds the report charts
- Lock and deadlock reports (`monitor.locks`) — not implemented
- Replication status (`monitor.replication`) — not implemented
- Threshold alerts (`monitor.alerts`) — not implemented

### Privileges

- Role membership editor (`priv.roles`) — memberships are shown in the grant list
- Privilege audit report (`priv.audit`) — not implemented

### Report

- Report designer with layout (`report.designer`) — not implemented; charts are live views
- BI dashboard (`report.biDashboard`) — not implemented
- Export a report (`report.export`) — export the underlying result as csv or markdown

### Modeler

- Reverse engineer a model (`diagram.reverseEngineer`) — the diagram is generated from the live catalog
- Forward engineer a model to DDL (`diagram.forwardEngineer`) — use schema.createTable or sync.structure
- Move boxes by hand (`diagram.manualLayout`) — not implemented; the layout is deterministic
- Save a model file (`diagram.modelFile`) — not implemented; the catalog is the source of truth

### Tools

- Code snippets (`sql.snippets`) — built-in set plus your own
- Data profiling (`tools.dataProfiling`) — not implemented; use an aggregate report
- Data dictionary export (`tools.dataDictionary`) — schema.ddl plus the diagram SVG
- Server-wide search (`tools.serverSearch`) — schema.search covers the cached catalog
- Import a text file as a table (`tools.textImporter`) — not implemented
- Auto-update (`tools.updater`) — not implemented; builds are local

### Cloud

- Team collaboration (`cloud.team`) — not implemented
- Cloud-synced settings (`cloud.syncSettings`) — settings are JSON on this machine
- Shared query library (`cloud.sharedQueries`) — snippets are local to this machine

### Platform

- JSON control channel (`platform.control`) — drive the running app over a local socket
- Command line tool (`platform.cli`) — nook-cli exists and shares command ids; not a command itself
- Localisation (`platform.i18n`) — English only for now
- Windows build (`platform.windows`) — not built here; cargo builds it
- Linux build (`platform.linux`) — not built here; cargo builds it
- Browser build (`platform.web`) — not implemented; this is a native tool
